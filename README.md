### Lume Piano

The interactive piano lives at `/piano` and is listed first in Projects. It uses local Web Audio synthesis (three timbres, 37 visible keys, octave shifting, transposition, sustain), a metronome, short melody excerpts, and browser-only audio recording with download. The melody library includes two public-domain melodies and a brief seven-note opening excerpt of John Williams’s “Hedwig’s Theme” from Harry Potter. No microphone permission or audio upload is needed. The support button opens [GitHub Sponsors](https://github.com/sponsors/joaosouz4dev).

Run `npm run dev` to try it, `node --test scripts/test-piano.mjs` for audio lifecycle tests, and `npm run build` to validate the production build and prerendered piano page. Recordings are limited to five minutes and are temporary until downloaded. The download format depends on browser support (WebM, M4A, or Ogg). Moving away from the window stops notes, playback, the metronome, and recording.
